# DSGVO-/DSG-Paket für OnLumis (AP 2.6)

> **Wichtiger Hinweis:** Diese Dokumente sind fachlich auf die
> OnLumis-Plattform zugeschnittene **Vorlagen**, keine Rechtsberatung. Vor
> Verwendung durch eine juristisch qualifizierte Person prüfen und an den
> Einzelfall (Kunde, Betriebsmodell, Schweizer DSG vs. DSGVO) anpassen.

| Dokument | Zweck |
|---|---|
| [avv-vorlage.md](avv-vorlage.md) | Auftragsverarbeitungsvertrag (Art. 28 DSGVO) zwischen Kunde und JULITH GmbH für Einrichtung/Betrieb |
| [toms.md](toms.md) | Technisch-organisatorische Maßnahmen – konkret auf die implementierten Plattform-Features bezogen |
| [loeschkonzept.md](loeschkonzept.md) | Löschkonzept: Quellen-Sync, Chats, Audit, Backups, Betroffenenrechte |
| [vvt-eintrag.md](vvt-eintrag.md) | Vorlage für das Verzeichnis von Verarbeitungstätigkeiten des Kunden |

Einordnung: Beim reinen On-Premise-Betrieb durch den Kunden ist der Kunde
Verantwortlicher und Betreiber; JULITH wird typischerweise nur im Rahmen von
Einrichtung/Support/Wartung zum Auftragsverarbeiter (Fernzugriff!). In der
Private-Cloud-Variante ist JULITH dauerhaft Auftragsverarbeiter.
